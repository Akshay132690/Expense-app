# Expense-app
# 💰 Expense Management System

**Thrilled to share my latest project:** a comprehensive **Expense Management System** designed to simplify personal finance tracking.

This application allows users to **effortlessly add, categorize, and view their transactions** with a modern, intuitive interface.

It’s been an incredible journey building it from the ground up, refining my full-stack development skills.

---

## ✨ Key Features

✅ **Intuitive User Interface**

* Seamless expense entry with clear, modern design.

✅ **Transaction Categorization**

* Organize expenses by category for better insights and budgeting.

✅ **Secure User Authentication**

* Ensures user data privacy and personalized experience.

---

## 🛠️ Technologies Used

### 🔹 Frontend

* **React.js** for a dynamic, component-based UI.
* **Ant Design** for beautiful, responsive styling.

### 🔹 Backend

* **Node.js** and **Express.js** for robust API handling and business logic.

### 🔹 Database

* **MongoDB Atlas** for flexible, scalable cloud data storage.

## ⚙️ How to Run Locally

### 1️⃣ Clone the repository

```bash
git clone https://github.com/your-username/expense-management-system.git
```

### 2️⃣ Install dependencies

#### Frontend

```bash
cd client
npm install
```

#### Backend

```bash
cd server
npm install
```

### 3️⃣ Add environment variables

* Create `.env` in `/server` with your MongoDB URI and any secret keys.

### 4️⃣ Start the app

#### Backend

```bash
npm run dev
```

#### Frontend

```bash
npm start
```
